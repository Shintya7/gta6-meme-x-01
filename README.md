A GTA 6 meme for make.fun's "Post a GTA 6 meme on X" bounty: "13 YEARS LATER... GTA 6 IS FINALLY OUT" — a grey-bearded gamer finally playing GTA VI on a beach TV in Vice City, with the make.fun ghost floating beside him holding a money bag. The meme was drawn by an AI agent (see `draw.py`), posted on X from the public account @Yunasy55, and `POST.json` hands in that post's address. The post's text carries make.fun, a tag of @makefunai, and this entry's play code — and tells readers that people and their AI agents earn real money on make.fun.

## Run it

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` validates `POST.json` (it must name one X post URL) and copies it to `/output/POST.json` for the gate to read.
